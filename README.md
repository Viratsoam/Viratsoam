👋 About Me
I'm a backend engineer with 5+ years of software development experience, focused on building dependable backend systems and practical AI applications. I like working on the engineering that makes AI useful beyond a demo: retrieval quality, clear tool interfaces, reliable workflows, and measurable behavior.
🤖 AI Engineering — LLM-powered workflows, structured outputs, tool calling, embeddings, and agentic application patterns.
🔎 Search & Retrieval — Elasticsearch, hybrid keyword and vector search, semantic retrieval, fuzzy matching, and relevance tuning.
⚙️ Backend Systems — Node.js, TypeScript, NestJS, Python, and FastAPI, with a focus on maintainable APIs and asynchronous processing.
🧱 Reliability — Queues, retries, idempotency, dead-letter handling, caching, audit trails, and operational visibility.
🏥 Domain Experience — Enterprise search and healthcare document workflows, including prior-authorization evidence processing.
📚 Currently Exploring — AI-first software engineering, agent evaluation, and robust tool-using workflows.
My approach is simple: make the system understandable, testable, and reliable—not just impressive in a demo.

🚀 Featured Engineering Work
Projects that reflect the kind of systems I enjoy building: search that returns useful results, AI workflows with clear boundaries, and backends designed to handle failure.
🔎 Lilo Search
Hybrid search for B2B e-commerce
Combines keyword search with vector retrieval to help product discovery. Includes fuzzy matching, synonym handling, data normalization, personalization, filters, and deep pagination.
Stack: NestJS · Elasticsearch · Embeddings · Next.js
📈 Ad Optima Engine
AI-assisted advertising analysis
Processes campaign metrics, calculates performance KPIs such as ROAS, ACOS, CTR, and CPC, and uses an LLM-powered workflow to generate optimization insights. Includes background jobs and progress tracking.
Stack: Node.js · TypeScript · LangChain · BullMQ · Redis
🏥 PA Evidence Pipeline
An auditable, event-driven document workflow
A backend workflow for prior-authorization intake, evidence extraction, and policy evaluation. The project focuses on idempotency, retries, dead-letter handling, and traceable processing.
Stack: NestJS · FastAPI · PostgreSQL · Redis
📄 Invoice Collector
Document automation from inbox to structured data
Explores message integrations, document retrieval, OCR, field extraction, file storage, and asynchronous processing for invoice collection.
Stack: NestJS · OCR · AWS S3 · Bull · Redis
